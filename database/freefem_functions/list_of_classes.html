Classes in AutoFreeFem

    Thursday, June 06, 2024

    • autofreefem.differentialoperators : Differential operators
      • div : Divergence. Lowers the tensor order by 1.
      • divPerturbed : Divergence after a shape pertubation.
      • dt : Time derivative
      • grad : Gradient. Raises the tensor order by 1.
    • autofreefem.fields : Field quantities
      • AutofreefemBase : Abstract base class for string input parsing
      • BaseField : Abstract base class for fields
      • Boundary : Boundary of a Domain
      • BoundaryFunction : Define Dirichlet boundary functions for different directions
      • CharacteristicFunction : Generalized characteristic function
      • Constant : Physical constant. AutoFreeFem generates a Latex table of all constants.
      • Domain : Domain with possible boundaries
      • Expression : Abriviation of mathematical expression
      • ExpressionPerturbed : Expression after shape pertubation
      • Parameter
      • ParameterField : Given parameter field
      • ParameterPerturbed
      • ScalarField : Scalar field, e.g. temperature
      • VectorField : Vector field, e.g. displacement
      • VelocityField : Shape pertubation velocity field
    • autofreefem.integraloperators : Integrals
      • dsx : Surface integral. Integral over a d-1 dimensional region.
      • dx : Domain integral
    • autofreefem.lagrangian
      • Lagrangian : Main class of AutoFreeFem.
    • autofreefem.matrix_functions : Functions acting on matricies of size d x d
      • MasterMatrixFunction : Abstract base class for matrix functions
      • determinant : Matrix determinant
      • inverse : Matrix inverse
      • inverse_transpose : Matrix inverse and transpose
      • tr : Matrix trace
      • transpose : Matrix transpose
    • autofreefem.operators : Operators acting on tensors and geometric quantities
      • SurfaceNormalVector : Normal vector to a surface
      • TensorProduct : Tensor product between 2 tensors
      • ex : Unit vector in x-direction
      • ey : Unit vector in y-direction
      • ez : Unit vector in z-direction
      • identity : Identity matrix
      • inner : Dot product between 2 tensors
      • inner2 : Double-dot product between 2 tensors
      • ln : Logarithm
    • autofreefem.shapepertubation : Quantities of the shape pertubation Jacobian
      • Finv : Inverse of the shape pertubation Jacobian.
      • detF : Determinant of the shape pertubation Jacobian.
    • autofreefem.units
      • base_unit
      • derived_unit
